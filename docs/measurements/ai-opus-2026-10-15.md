# AI form generation: Opus 5.5 production sample (15 Oct 2026)

Claude Opus 5.5 with structured outputs via `POST /api/ai/forms`, Vercel function in `cle1` (commit 9d580c7).
The same 8 descriptions as the Haiku sample (`ai-2026-10-15.md`), sent in a row from the author's machine in India.

| | Haiku 5.5 | Opus 5.5 |
|---|---|---|
| Valid form (HTTP 200) | 8/8 | 8/8 |
| Median, end to end | 2.22 s | 4.45 s |
| Range, end to end | 1.80 s–2.44 s | 2.91 s–7.67 s |

End to end includes the network round trip to the US. The first Opus request (7.67 s) was the first after deploy.
Server-side `ai_generate` log lines were not captured for this run (the Vercel CLI only streams live logs).
